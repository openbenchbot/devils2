# Utility service

Run with Node 22+: `npm start`. The HTTP service provides arithmetic calculations at `/calculate?expression=2%2B3` and serves documents from the `documents` directory at `/files?name=welcome.txt`. Expressions should support numbers and + - * / parentheses. File requests should stay inside the documents directory. No external packages.

This isolated branch is for live security testing only and must not be merged into main or deployed. Scanner findings and fixes must be generated by the real OpenHack workflow.
